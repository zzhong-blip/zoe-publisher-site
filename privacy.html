Privacy Policy

Last updated: August 26, 2026

Zoe Publisher uses YouTube API Services.

The application requests the YouTube OAuth scope https://www.googleapis.com/auth/youtube.upload solely to upload original videos owned and created by the application owner to the owner's own YouTube channel.

Zoe Publisher does not sell, rent, or share Google user data with third parties.

OAuth credentials are used only for authenticated YouTube uploads. The application does not use Google user data for advertising or profiling.

Users may revoke Zoe Publisher's access at any time through their Google Account permissions.

Zoe Publisher's use of information received from Google APIs adheres to the Google API Services User Data Policy.
